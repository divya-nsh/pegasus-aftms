AFTMS Server Setup

Connect the server to PostgreSQL to finish installation.

Before you continue
  • PostgreSQL must be installed and running (version 18 recommended). Don't have it yet? PostgreSQL: Downloads
  • Keep your connection details ready: host, port, username and password.
  • Use an existing AFTMS database, or enter a new name and it will be created for you.
  • Default App User is Admin and Password admin.

Database (PostgreSQL)
If this database doesn't exist, it will be created automatically. That needs a user with the CREATEDB permission (the default postgres user has it). If you use a restricted user, create the empty database first.
